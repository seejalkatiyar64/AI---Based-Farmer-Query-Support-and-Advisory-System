🌾 AI-Based Farmer Query Support and Advisory System (KrishiMitra)

🎯 Project Overview
AI-Based Farmer Query Support and Advisory System (KrishiMitra) is an intelligent web-based platform designed to assist farmers by providing instant answers to agriculture-related queries. The system uses Artificial Intelligence to offer guidance on crop management, pest control, fertilizers, irrigation practices, weather-related concerns, and modern farming techniques. The goal of this project is to bridge the information gap between farmers and agricultural experts by providing quick, reliable, and accessible advisory support. ✨ Features 🤖 AI-powered chatbot for farmer queries 🌱 Crop management recommendations 🐛 Pest and disease identification guidance 💧 Irrigation and fertilizer suggestions 🌦️ Weather-related farming advice 📱 User-friendly interface ⚡ Real-time responses using AI models

🧠 How Each Feature Works
1. Dashboard
Shows farmer profile (stored in React state, editable)
Real-time weather card with 5-day forecast (mock data)
Smart alerts generated by rule-based prediction engine
Crop health progress bars
Rotating marquee alerts
2. AI Chatbot
Powered by Claude Sonnet API (called directly from browser)
System prompt includes farmer profile + current weather
Responds in Hindi by default
Voice input via Web Speech API (webkitSpeechRecognition)
Conversation history maintained in component state
3. Disease Detection
Drag-and-drop or tap-to-upload image
Frontend preview with FileReader API
Calls /upload backend endpoint
Backend runs mock classifier (replace with Plant.id or TF Serving)
Returns disease name, confidence %, treatment, prevention steps
4. Profit Calculator
Select two crops, adjust area with slider
Calculates cost, revenue, profit, ROI per hectare × area
Comparison table with winner highlighted
"AI Analysis" button calls Claude for personalized recommendation
Government schemes listed at bottom
5. Rule-Based Prediction Engine (Backend)
IF humidity > 80% AND temp > 25°C → fungal risk HIGH
IF temp > 30°C AND humidity < 40% → aphid pest risk HIGH  
IF rain > 50% → irrigation alert
IF temp < 5°C → frost risk CRITICAL
6. IVR / Missed Call System (Concept)
Farmer dials a number → call drops (missed call)
System receives webhook → looks up farmer profile
Generates Hindi voice script
Calls back using Twilio/Exotel with personalized alert
POST /ivr/missed-call endpoint simulates this flow
7. Offline Mode (Concept)
Service Worker caches app shell + static assets
Last weather data stored in localStorage
AI suggestions pre-generated and cached
Sync when connectivity restored
🌐 API Endpoints
Method	Endpoint	Description
GET	/health	Health check
POST	/chat	AI chatbot response
POST	/predict	Pest/disease risk prediction
POST	/upload	Image upload + disease detection
GET	/weather?city=Pune	Weather data
POST	/profit	Crop profit calculation
GET	/farmer/:id	Get farmer profile
POST	/farmer	Create farmer profile
PUT	/farmer/:id	Update farmer profile
POST	/ivr/missed-call	IVR simulation
